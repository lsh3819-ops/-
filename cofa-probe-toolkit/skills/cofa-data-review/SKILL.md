# 연습 데이터와 결과 점검

이 스킬은 새로 작성한 예시다. 실제 설치 환경이나 COFA Probe 시험 규격을 알고 있다고 가정하지 않는다.

사용자가 제공한 데이터 설명, 문제 조건과 계산 목적을 먼저 확인한다. 열 이름만으로 측정 단위, 정상 범위, 불량 판정 기준을 확정하지 않는다. 필수 정보가 없으면 가능한 품질 점검을 진행하고 판단에 필요한 질문만 남긴다.

원본은 보존한다. 행 수, 누락값, 중복, 자료형, 단위 혼용과 값 범위를 점검한다. 데이터에 식별자나 시간 열이 있으면 그 의미가 확인된 범위에서 그룹별 편중과 시간 순서를 살핀다. 이상치는 표시하고, 임의 삭제나 단위 변환은 분석 가정으로 명시한다.

비율은 분자와 분모를 함께 적고 중복 측정 및 결측 처리 방식을 밝힌다. 예측 과제라면 학습·평가 사이의 개체 중복과 시간 누출을 확인한다. 근거 없이 통계적 연관을 인과관계나 공정 불량 원인으로 단정하지 않는다.

결과에는 입력 범위, 확인한 사실, 가정, 재현 가능한 계산 방법, 미해결 항목을 담는다. 입력이 없으면 실제 분석 결과를 만들어내지 말고 필요한 입력을 설명한다.

외부 서비스로 데이터를 전송하는 행위는 이 스킬의 사용만으로 허가되지 않는다. 사용자 요청과 시험의 허용 범위에 맞춰 처리한다.
