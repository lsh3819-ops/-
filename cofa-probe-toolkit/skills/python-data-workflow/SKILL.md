# Python 데이터 분석과 검증

이 스킬은 신규 작성한 워크플로이며 설치된 스킬의 복사본이 아니다.

프로젝트의 기존 의존성·Python 버전·테스트 구조를 확인하고 사용자 목적에 필요한 도구만 사용한다. pandas는 표 정리, DuckDB는 SQL 집계, pytest는 계산과 처리 계약 검증에 활용한다. 세 도구를 모든 작업에 강제로 적용하지 않는다.

CSV의 식별자는 선행 0이 보존되도록 자료형을 결정한다. 결측값, 중복, 시간대와 단위를 명시하고 원본은 보존한다. DuckDB 조인 전 키의 유일성을 확인하고 조인 후 행 수 증가와 집계 중복을 점검한다. 외부 입력 값을 SQL 문자열에 직접 합치지 말고 파라미터로 전달한다.

테스트는 의미 있는 경계값과 불변조건을 확인한다. 예를 들어 빈 데이터 처리, 분모 0, 중복 키 조인, 결측값 정책과 예상 집계 결과를 검증한다. 재현에는 합성 자료를 우선 사용한다.

현재 버전의 API가 불확실하면 Context7 또는 공식 문서를 확인한다. 내부 데이터와 비밀정보를 검색 쿼리에 포함하지 않는다. 실제 실행한 명령·버전·결과와 미실행 부분을 구분해 보고한다.
